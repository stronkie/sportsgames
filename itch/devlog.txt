TITLE: One disk! Stronkie's Olympics V0.5 - the whole game crunched onto one floppy

Three disks meant a lot of swapping, so I wrote my own cruncher for Stronkie's Olympics. Now the whole game fits on ONE floppy disk.

WHAT'S NEW IN V0.5
- All 18 events, the opening and closing ceremonies, the national anthems and the world records now fit on one bootable disk. No more "PLEASE INSERT DISK 2".
- Every file on the disk is crunched to about half its size: 1.75 MB of game on one 880K floppy.
- Faster loading from floppy: the Amiga reads less than half as much from the disk, and unpacking an event takes only about a second on a 7 MHz 68000.
- It still runs on a plain Amiga 500 with 512K + 512K: everything is unpacked in place, so no extra memory is needed.
- The free demo is crunched too.
- The manual, the disk label and the box are remade for one disk (free downloads on the page).
- The hard drive and WHDLoad versions work just like before.

FOR THE CODERS
The cruncher is an LZ77 packer with gamma-coded lengths and offsets and a cheap "same offset again" match, which suits Amiga bitplane graphics. Each hunk of the program is packed on its own. While it loads, the packed bytes are read to the end of the hunk's memory and unpacked forwards from the start, so the depacker needs no buffer at all.

This is still a TEST VERSION. Please tell me in the comments how it runs on your Amiga!
